## 说明

- **照片**：全部为新人的 13 张婚纱照，按模板节奏摆放（通栏横图 / 圆徽章 / 竖版拼贴 / 双列照片墙）。
- **背景与装饰**：淡纸纹背景、红色手绘曲线、「喜」字、竖排文字均为本项目自制（CSS / SVG），未使用任何第三方模板素材。
- **文案**：邀请语、英文句、谢谢你等均为新写的同调文字；请柬三行与题诗为新人自己的内容。
- **音乐**：`music.mp3` 放在根目录，页面首次点击后自动播放，右上角音符按钮可开关，
  底部「点击播放音乐」提示胶囊在播放后自动隐藏。

## 想换成真视频？

把视频命名为 `video.mp4` 放根目录，第 8 屏的小电影会自动改播这个视频（照片电影自动隐藏）。建议 1080p、20MB 以内。

## 文件结构

```
index.html                 页面结构（文案在这里改）
assets/css/style.css       样式（配色、排版、动效）
assets/js/main.js          交互（花瓣、日历、倒计时、小电影、相册、留言、导航）
assets/js/photos-data.js   自动生成：照片尺寸与模糊占位图
photos/pXX.jpg             大图（长边 1600px）
photos/thumb/pXX.jpg       缩略图（长边 900px）
music.mp3 / video.mp4      可选，放根目录即生效
```

## 常见修改

- 名字 / 日期 / 地点 / 文案 → `index.html`
- 倒计时时间 → `assets/js/main.js` 顶部 `WEDDING_TS`
- 导航关键词 → `assets/js/main.js` 顶部 `ADDRESS`、`VENUE`
- 相册分组顺序 → `assets/js/main.js` 顶部 `CHAPTERS`
- 配色 → `assets/css/style.css` 顶部 `:root`

## 本地预览与部署

```bash
npx serve .            # 或 python -m http.server 8080
```

仓库 `Settings → Pages → Source`：分支 `main`、目录 `/ (root)`。
