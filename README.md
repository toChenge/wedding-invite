## 版式特点

- **文字在图片侧边**：邀请语、请柬三行、新人、喜字、日期、题诗、地点都是「左文右图 / 左图右文」交替排版
- **中英混排 + 艺术字**：英文用手写体（Snell Roundhand / Segoe Script）与衬线展示体（Didot）宽字距，
  中文标题用行楷（Xingkai / 华文行楷），名字用宋体
- 淡纸纹背景、红色手绘曲线、「喜」字、竖排文字均为自制（CSS / SVG）

## 说明

- **音乐**：`music.mp3` 已用 ffmpeg 压到 **96kbps / 2.4MB**（原 320kbps / 8MB，省 70%），
  页面首次点击后自动播放；右上角音符按钮可开关，底部「点击播放音乐」胶囊在播放后自动隐藏。
  原始文件备份在 `_probe/music-original.mp3`（不会上传）。
- **留言表单**：纯静态无后端，提交后生成祝福卡片并复制到剪贴板，粘贴到微信发给新人即可。

## 文件结构

```
index.html                 页面结构（名字 / 日期 / 地点 / 文案）
assets/css/style.css       样式（侧边排版、艺术字、配色、动效）
assets/js/main.js          交互（花瓣、日历、倒计时、小电影、相册、留言、导航）
assets/js/photos-data.js   自动生成：照片尺寸与模糊占位图
photos/pXX.jpg             大图（长边 1600px）
photos/thumb/pXX.jpg       缩略图（长边 900px）
music.mp3 / video.mp4      可选，放根目录即生效
```

## 常见修改

- 文案 / 版式文字 → `index.html`（侧边排版就是 `.side` 与 `.side.rev` 两个 class）
- 倒计时时间 → `assets/js/main.js` 顶部 `WEDDING_TS`
- 导航关键词 → `assets/js/main.js` 顶部 `ADDRESS`、`VENUE`
- 相册分组 → `assets/js/main.js` 顶部 `CHAPTERS`（删掉照片后会自动跳过，不用改代码）
- 配色 / 字体 → `assets/css/style.css` 顶部 `:root`
