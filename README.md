## 背景音乐

`music.mp3` 已放在根目录，打开请柬时会自动播放，右上角音符按钮可随时开关。
（音乐请自行确认版权；换成别的歌只要覆盖同名文件即可。）

## 想换成真视频？

把你们拍的视频命名为 `video.mp4` 放在根目录，婚礼小电影会自动改成播放这个视频（照片电影自动隐藏）。
建议压到 1080p、20MB 以内，微信里加载更快。

## 文件结构

```
index.html                 页面结构（文案在这里改）
assets/css/style.css       样式（配色、排版、动效）
assets/js/main.js          交互（倒计时、小电影、相册、灯箱、撒花、导航）
assets/js/photos-data.js   自动生成：照片尺寸与模糊占位图
photos/pXX.jpg             相册大图（长边 1600px）
photos/thumb/pXX.jpg       相册缩略图（长边 900px）
music.mp3 / video.mp4      可选，放进根目录即生效
```

## 常见修改

- **改文案 / 名字 / 日期**：编辑 `index.html`
- **改倒计时时间**：`assets/js/main.js` 顶部 `WEDDING_TS`
- **改地址 / 导航关键词**：`assets/js/main.js` 顶部 `ADDRESS`、`VENUE`
- **换照片**：新照片按 `p01.jpg`、`p02.jpg` … 命名，分别放进 `photos/`（大图）与 `photos/thumb/`（缩略图），
  再到 `assets/js/main.js` 的 `CHAPTERS` 里调整分组顺序
- **改配色**：`assets/css/style.css` 顶部 `:root` 变量
